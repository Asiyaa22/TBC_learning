We are learning Pseudo-class and Pseudo-elemnts

Pseudo-class and pseudo-elements in css are powerful selectors which allows you to style the elements in specific ways
Pseudo-class is used to define the special state of an element and they allow us to style the state of an element. That is we can style the element based on the state of element or how it is interacted with. Like we can style the element when the user hovers over it or when the user clicks on it.
while pseudo-elements are used to style the specified parts of an element. They allow us to style the specific parts of an element. Like we can style the first letter of a paragraph or the first line of a paragraph.
